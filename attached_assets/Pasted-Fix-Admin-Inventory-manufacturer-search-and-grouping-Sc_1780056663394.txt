Fix Admin Inventory manufacturer search and grouping.

Scope:
Admin Inventory only.

1. Searching by manufacturer name does not work.
Example:
Searching "ABB", "Siemens", "Eaton", or "LS Electric" should return matching inventory groups/items.

2. Items with the same group/family name but different manufacturers are still grouped under the same header.
Example:
ABB 600V Indoor Non-Fused Disconnect Switch
Siemens 600V Indoor Non-Fused Disconnect Switch

These should be separate Admin Inventory groups, not merged into one group.

Required changes:

1. Search should include manufacturerName

Update Admin Inventory search logic so the search query checks:
- SKU
- item name
- size
- family/group name
- type/subcategory if currently searched
- manufacturerName

Examples:
Search "ABB" should show ABB items/groups.
Search "Siemens" should show Siemens items/groups.
Search "LS Electric" should show LS Electric items/groups.

Search should be case-insensitive.

2. Grouping key should include manufacturerName when present

Current grouping likely uses only family/group name.

Update Admin Inventory grouping only:

If manufacturerName exists:
groupKey = manufacturerName + family/group identifier

If manufacturerName is blank/null:
groupKey = existing family/group identifier

This prevents different manufacturers with the same item/family name from being merged.

Example:
manufacturerName = ABB
familyName = 600V Indoor Non-Fused Disconnect Switch
→ group should be:
ABB 600V Indoor Non-Fused Disconnect Switch

manufacturerName = Siemens
familyName = 600V Indoor Non-Fused Disconnect Switch
→ separate group:
Siemens 600V Indoor Non-Fused Disconnect Switch

Example:
ABB 600V Indoor Non-Fused Disconnect Switch

If manufacturerName is blank:
- Keep the current header display unchanged.

Do not repeat manufacturerName in every child size row if the group header already shows it.

Rows should stay compact.
