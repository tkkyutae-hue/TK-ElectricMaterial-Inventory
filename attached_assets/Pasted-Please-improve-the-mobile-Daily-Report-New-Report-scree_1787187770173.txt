Please improve the **mobile Daily Report / New Report screen UI** shown in the attached reference.

This task has two main goals:

1. Fix the horizontal overflow caused by the 3 navigation tabs.
2. Reorganize the **General Info** section using the existing information so it is easier to read and more space-efficient on mobile.

Do not change business logic, data logic, routes, or submission behavior.

# 1. Fix the 3 Mobile Navigation Tabs

The horizontal page scrolling is currently caused by these 3 tabs directly below the header:

* New Report
* Report History
* Project Progress / Progress

English and Spanish labels are longer than Korean and are increasing the intrinsic width of the tab container.

Korean works because the labels are shorter.

## Required mobile behavior

All 3 tabs must always fit within the mobile viewport.

Use a true responsive 3-column layout:

```css
grid-template-columns: repeat(3, minmax(0, 1fr));
width: 100%;
```

Each tab must have:

```css
min-width: 0;
max-width: 100%;
```

Long translated labels must be allowed to wrap.

Do not use `white-space: nowrap` on the mobile labels.

Do not shorten or modify translations just to make them fit.

Example:

```text
┌────────────┬────────────┬────────────┐
│     +      │     ▣      │     ▥      │
│ New Report │ Report     │ Project    │
│            │ History    │ Progress   │
└────────────┴────────────┴────────────┘
```

Maximum 2 lines for the label is preferred.

The icon may be slightly smaller on narrow mobile screens.

Reduce unnecessary horizontal padding and gap between icon/text if needed.

### Important

Do not solve the issue only with:

```css
overflow-x: hidden;
```

Fix the actual layout width.

There must be:

* No horizontal page scrollbar
* No clipped tabs
* No tab extending outside the viewport
* All 3 tabs visible simultaneously
* Correct behavior in Korean, English, and Spanish

Test at:

* 320px
* 360px
* 375px
* 390px

# 2. Reorganize General Info

The current General Info screen contains the right information, but the layout is inefficient.

The top project summary currently compresses too much information into one small horizontal row:

```text
PODI...   PO: TKM101026   Working on it
HMGMA                      Hyungjoon Jang
```

This causes:

* Project name truncation
* PO number being difficult to see
* Poor information hierarchy
* Excess empty/uneven space
* Localization issues with English/Spanish

Reorganize the existing information into three visual groups:

1. Project Summary
2. Report Details
3. Reporter / Project Manager / Validation
