We are planning to add asset tracking inside the existing Inventory system.

Goal:
Add a new inventory category:

TOOLS & ASSETS

This category should not work like normal quantity-based material inventory.

Normal materials:
- quantity tracking
- size rows
- receive / issue by quantity

Tools & Assets:
- individual asset tracking
- each tool has its own Asset ID
- status, condition, location, project, repair status, and history must be tracked per asset
