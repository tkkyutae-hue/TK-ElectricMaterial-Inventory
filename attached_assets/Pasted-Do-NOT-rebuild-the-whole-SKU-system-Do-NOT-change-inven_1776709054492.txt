PART 3 — SIZE NORMALIZATION RULES
==================================================

Normalize cable/wire sizes using these exact conventions:

- #12  -> 12
- #10  -> 10
- #8   -> 8
- #6   -> 6
- #4   -> 4
- #2   -> 2
- #1   -> 1
- #1/0 -> O1
- #2/0 -> O2
- #3/0 -> O3
- #4/0 -> O4
- 250 kcmil -> 250
- 350 kcmil -> 350
- 500 kcmil -> 500

IMPORTANT:
Use capital letter O, not zero, for /0 sizes.
Examples:
- O1 = 1/0
- O2 = 2/0
- O3 = 3/0
- O4 = 4/0

==================================================
PART 4 — CONFIG NORMALIZATION RULES
==================================================

For multi-conductor cable, standardize config exactly as:

- 2C   = 2 conductor
- 2CG  = 2 conductor + ground
- 3C   = 3 conductor
- 3CG  = 3 conductor + ground
- 4C   = 4 conductor
- 4CG  = 4 conductor + ground

Do NOT allow mixed formats like:
- 2C+G
- 2C-G
- 2 conductor ground
- etc.

Normalize them into the standard config tokens above.
