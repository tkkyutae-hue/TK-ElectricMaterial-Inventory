TK ELECTRIC · 검토용 / SYNTHETIC DATA

필드모드 자재 탐색·필터 개선안

실제 앱과 연결하지 않은 분리 모의 화면입니다. 저장·입출고·요청 제출 기능을 실행하지 않습니다.

기존 직원 DB, 실제 앱 코드, 공통 Select, 오류 진단 코드, 설정과 배포는 변경하지 않았습니다. 기존 카테고리 사진을 대체하는 제안이 아닙니다.

검증 범위

  • 36개 자동 검사 통과: 320/390/768/1024/1440 × 한국어/영어/스페인어 × 밝음/어두움의 8개 상태 = 240개 상태 조합.
  • 5개 화면 폭에서 필터 적용·개별 해제·초기화·카테고리 변경·상세 필터 초점 가두기/복귀·하단 카트 가림 검사.
  • 다중 조건 결과수, 사진 누락/깨짐 구분, 사진 확대, 재시도, 카트 수량, 품절/조회 오류 구분 확인.
  • 네트워크 요청과 업무 호출은 차단·검사했고 0건입니다. 앱 서버와 기존 DB는 사용하지 않았습니다.
  • 모의 컴포넌트의 별도 TypeScript 검사 통과.

통합 전 남은 확인

  • 미해결 선택창 오류의 진단 코드를 보존하고 원인 확인과 통합 시점을 조정해야 합니다.
  • 실제 필터 API의 분류 연결·결과수·페이지 나누기 정합성은 검증하지 않았습니다.
  • 실제 카테고리/제품 사진과 기존 카트·릴/자재 상세 흐름을 보존하여 연결해야 합니다. DB에서 사진을 조회하지 않았습니다.
  • 이 결과는 Chromium 모의 화면 검사입니다. 실제 모바일 기기, Safari, 전체 스크린리더/WCAG 감사, 운영 데이터 동작은 미검증입니다.
  • 한글 캡처는 이미 설치돼 있던 로컬 Nanum 글꼴을 메모리에만 넣어 생성했습니다. 새 패키지·글꼴 설치 및 외부 다운로드는 없습니다.

실제 앱 통합·스키마 변경·재시작·배포는 별도 승인 전 진행하지 않습니다.
