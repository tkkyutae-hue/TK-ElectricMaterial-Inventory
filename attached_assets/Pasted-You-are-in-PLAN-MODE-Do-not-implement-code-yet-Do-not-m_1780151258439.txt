We are planning a major Admin Inventory UI structure improvement.

Current problem:
Admin Inventory currently shows many item/family cards in one long list.
As the number of items grows, it becomes difficult to manually organize related items using drag-and-drop.

Goal:
Refactor Admin Inventory display into a 3-level collapsible structure:

Category
  Family Header
    Item Header
      Size Rows

Example:

CONDUIT & FITTINGS

▸ EMT
    ▸ EMT Conduit
        1/2"
        3/4"
        1"
    ▸ EMT Set Screw Connector
        1/2"
        3/4"
        1"

▸ Rigid
    ▸ Rigid Conduit
    ▸ Rigid Coupling

Important clarification:
Do NOT create a new Section Group concept.
Family Header should be generated from the existing Family value/data.
This is not a new taxonomy system.
This is an Admin Inventory display/grouping improvement.

Final desired behavior:
1. Existing family values automatically become collapsible Family Headers.
2. When all Family Headers are collapsed, only Family Headers are visible.
3. Clicking a Family Header expands it and shows Item Headers inside.
4. Clicking an Item Header expands it and shows existing size rows.
5. Family Headers should support drag-and-drop ordering.
6. Item Headers should support drag-and-drop ordering only within the same Family Header.
7. Size Rows should not use drag-and-drop. Keep existing size sort.
8. Collapse/expand should not change ordering.
9. Family Settings save should not move the group to the bottom.
10. Drag-and-drop order should persist after refresh, navigation, collapse/expand, and settings save.
11. New Family values should automatically create new Family Headers.
12. New Family Headers should appear at the bottom of the category until manually reordered.
13. Empty Family Headers should not display.
14. Family Header representative image should use this fallback:
    - explicit family representative image if available
    - first child item header image
    - first child item image
    - placeholder
