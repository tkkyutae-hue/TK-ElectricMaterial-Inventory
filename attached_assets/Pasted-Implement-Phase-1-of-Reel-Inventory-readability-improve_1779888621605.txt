Implement Phase 1 of Reel Inventory readability improvement.

Context:

Add a client-side helper:
parseWireConfig(item)

Input:
- item.name
- item.sizeLabel
- item.baseItemName if useful

Output:
{
  coreTypeLabel: string | null,
  sizeLabel: string | null,
  conductorColorLabel: string | null
}

Parsing rules:
1. Size:
- Prefer item.sizeLabel.
- Display with # prefix for AWG if needed.
- Keep 1/0, 2/0, 3/0, 4/0 readable.
- Keep 250, 350, 500 as kcmil if item name implies kcmil or large conductor.

2. Multi Core:
If item.name contains patterns like:
- (4C+G)
- 4C+G
- 3C+G
- 2C
- 3C
- 4C
Then:
- coreTypeLabel = "Multi Core"
- conductorColorLabel = matched config, e.g. "4C+G"

3. Single Core:
If no multi-core conductor config is found:
- coreTypeLabel = "Single Core" for wire/cable items where unit is FT or reel UI is shown.
- conductorColorLabel can be detected from color words:
  - Green / GRN / Ground → "Green" or "Ground"
  - Black / BLK → "Black"
  - White / WHT → "White"
  - Red → "Red"
  - Blue / BLU → "Blue"
  - Brown, Orange, Yellow, Gray if found
- If no color is found, show "—".

4. Fallback:
If parsing fails:
- show "—"
- do not crash
- do not block reel display

New columns:
REEL ID | CORE TYPE | SIZE | CONDUCTORS / COLOR | LENGTH (FT) | BRAND | LOCATION | STATUS

Update WireItemReelSection similarly if it has a reel table:

Do not make the table visually crowded.
Keep columns narrow and readable.
