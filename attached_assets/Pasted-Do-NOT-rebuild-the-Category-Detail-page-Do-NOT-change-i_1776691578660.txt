PART 1 — FIX FALSE SUCCESS TOASTS
==================================================

Current problem:
CategoryDetail.saveInlineEdits() uses fetch() inside Promise.all() for item update/create/image patch requests, but does not check response.ok.

Because of that:
- server-side 400/500 responses do NOT reject
- Promise.all resolves
- success toast appears
- but the item is not actually created/updated

Required fix:
1. For every fetch request inside saveInlineEdits():
   - update existing item
   - patch image
   - create new item
2. Check res.ok explicitly
3. If not ok:
   - parse the error response if possible
   - throw a real Error
4. Only show the success toast after all requests have truly succeeded
5. If any request fails, show the destructive error toast with the real message
