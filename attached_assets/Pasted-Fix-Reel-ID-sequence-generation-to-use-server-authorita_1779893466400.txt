This endpoint includes all reels, active + inactive, and should be used for new reel creation.

With a React Query call to:
GET /api/wire-reels/${item.id}/next-id

Use credentials: "include".

Example pattern:
useQuery({
  queryKey: ["/api/wire-reels", item.id, "next-id"],
  queryFn: async () => {
    const res = await fetch(`/api/wire-reels/${item.id}/next-id`, {
      credentials: "include",
    });
    if (!res.ok) throw new Error("Failed to load next reel id");
    return res.json();
  },
  enabled: Boolean(item?.id),
});
