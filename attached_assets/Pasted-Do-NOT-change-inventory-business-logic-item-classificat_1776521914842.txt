TASK GOAL
Improve the Excel export grouping so similar items inside the same Family/Subcategory and Type/DetailType are separated into their own subgroup sections.

CURRENT PROBLEM
The export currently:
- sorts by subcategory → detailType → baseItemName → sizeSortValue
- but only creates visible group rows for:
  1. subcategory
  2. detailType

Because of that, items like:
- Metal Flexible Conduit Connector 90°
- Metal Flexible Conduit Connector Straight

are sorted near each other but still appear under one shared "Fittings" block with no visible subgroup separation.

REQUIRED CHANGE
Add a third visible grouping level in the Excel export:

Level 1:
- subcategory (existing)

Level 2:
- detailType (existing)

Level 3:
- baseItemName (new subgroup row)

Example desired structure:
- Metal Flexible
  - Fittings
    - Metal Flexible Conduit Connector 90°
      rows...
    - Metal Flexible Conduit Connector Straight
      rows...

This same behavior should also help other similar inventory groups, such as:
- bushing / locknut
- connector / coupling
- straight / 90 / reducer style variants
- any case where multiple distinct baseItemName values currently collapse visually into one shared Type section
